# Исправление визуального ввода кириллицы, ограничение размеров окон на macOS и автоматическое тестирование

## Результат (Outcome)
- Разработан и внедрен специализированный компонент `SanitizedTextField` с двусторонней синхронизацией визуального и логического состояния `@State -> Binding -> Model`. Это полностью устранило проблему визуального обхода фильтрации в SwiftUI на iOS и macOS (когда некорректные символы, отфильтрованные моделью через `didSet`, продолжали отображаться в текстовом редакторе).
- Все поля формы `ServerConnectionFormFields` переведены на использование `SanitizedTextField`.
- Полностью заблокировано произвольное изменение размера окон настройки сервера на macOS путем жесткой фиксации размеров контейнера `.frame(width: 480, height: 500)` в `ServerFormView.swift`.
- Создан новый автоматизированный тестовый набор `SanitizedTextFieldTests.swift`, полностью подтверждающий корректность очистки кириллицы, пробелов, длины и формата вводимых данных для хоста, порта, пути и пароля. Все 479 тестов успешно проходят сборку и верификацию.

## Что сработало хорошо (What Worked)
- **Локальное состояние в `SanitizedTextField`:** Использование `@State` для отображения текста с синхронизацией через `.onChange` позволило обойти баг оптимизации SwiftUI, из-за которого текстовые поля не перерисовывали visual state при идентичном programmatic state.
- **Интеграция с Xcode Native инструментами:** Сборка проекта и прогон тестов выполнялись через нативные MCP инструменты, гарантируя полную синхронность состояния проекта.

## Риски и допущения (Mistakes / Risks)
- Сбой Periphery: Утилита Periphery выдает ошибку декодирования Xcode проекта из-за формата поля `shellScript` в `.xcodeproj`. Это внешняя проблема, не связанная с нашими изменениями.
- Тест `observeBroadcastsPromptsToMultipleSubscribers` в `TransmissionTrustPromptCenterTests` является нестабильным (flaky) из-за асинхронного запуска задач в неизолированном контексте. При повторном прогоне все тесты проходят успешно на 100%.

## Извлеченные уроки (Learned Patterns)
- При фильтрации ввода в SwiftUI реактивные `Binding` с обработкой `set` могут рассинхронизироваться с реальным текстовым полем на экране, если новое отфильтрованное значение совпадает с предыдущим состоянием модели. Использование промежуточного `@State` в обертке над текстовым полем — это наиболее надежный способ принудительного обновления интерфейса.
