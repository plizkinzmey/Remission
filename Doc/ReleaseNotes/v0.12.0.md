## What's New in 0.12.0

### English
This release focuses on Transmission 4.1+ compatibility and a safer release/testing workflow.

#### Transmission API
- Added dual-mode RPC transport with automatic protocol selection:
  - `Legacy RPC` for older servers.
  - `JSON-RPC 2.0` for newer servers.
- Added automatic fallback from JSON-RPC 2.0 to legacy RPC when server capabilities are incompatible.
- Added protocol mode diagnostics so you can see which RPC mode is currently used.
- Added support for `rpc-version-semver` in handshake/capability mapping.
- Improved JSON-RPC error normalization and mapping to internal API errors.
- Improved request/response compatibility mapping for mixed key styles (`snake_case`, legacy variants).

#### Stability and Data Mapping
- Fixed torrent add response mapping (`torrent-added` / `torrent-duplicate`) in compatibility paths.
- Improved early RPC error handling in torrent mapping flows (`torrent-get`, `torrent-add`) to avoid misleading decode failures.
- Improved session and torrent domain mapping robustness for new Transmission payload variants.

#### Testing and Developer Experience
- Added focused RPC mode tests (`TransmissionClientRPCModeTests`) for protocol negotiation/fallback behavior.
- Added and stabilized a minimal macOS UI smoke test for app startup/list state.
- Added platform-aware test runner script:
  - `Scripts/test-platform.sh` (`macos-unit`, `macos-ui`, `macos-all`, `ios-sim`).
- Updated scheme/test plan setup to make macOS testing more predictable in Xcode.

### Русский
Этот релиз сфокусирован на совместимости с Transmission 4.1+ и более надежном процессе тестирования/релиза.

#### API Transmission
- Добавлен двухрежимный RPC-транспорт с автоматическим выбором протокола:
  - `Legacy RPC` для старых серверов.
  - `JSON-RPC 2.0` для новых серверов.
- Добавлен автоматический fallback с JSON-RPC 2.0 на legacy RPC при несовместимых возможностях сервера.
- Добавлена диагностика выбранного режима протокола, чтобы видеть, какой RPC-режим используется сейчас.
- Добавлена поддержка `rpc-version-semver` в handshake/capability mapping.
- Улучшена нормализация JSON-RPC ошибок и их маппинг во внутренние API ошибки.
- Улучшен слой совместимости ключей ответа/запроса для смешанных стилей (`snake_case` и legacy-варианты).

#### Стабильность и маппинг данных
- Исправлен маппинг ответа при добавлении торрента (`torrent-added` / `torrent-duplicate`) в режиме совместимости.
- Улучшена ранняя обработка RPC-ошибок в потоках маппинга (`torrent-get`, `torrent-add`), чтобы исключить ложные ошибки декодирования.
- Повышена устойчивость session/torrent маппинга к новым вариантам payload от Transmission.

#### Тесты и DX
- Добавлены целевые тесты RPC-режимов (`TransmissionClientRPCModeTests`) для проверки negotiation/fallback.
- Добавлен и стабилизирован минимальный macOS UI smoke-тест запуска и базового состояния списка.
- Добавлен платформенный скрипт запуска тестов:
  - `Scripts/test-platform.sh` (`macos-unit`, `macos-ui`, `macos-all`, `ios-sim`).
- Обновлены схема и test plan для более предсказуемого запуска macOS-тестов в Xcode.

## Notes
- Existing server configurations remain compatible; no migration steps are required.
- No breaking changes in user-facing behavior are expected.
